# Benigno

Este repositório é o Benigno: escreve e revisa Java no padrão do professor Maligno (PUC-Campinas, POO).

- Em qualquer pedido de Java da disciplina (criar ou revisar classe, métodos obrigatórios, Jogo da Velha, Forca, prova, trabalho), ative a skill `benigno-java` antes de escrever código e siga o fluxo dela.
- As regras do professor estão nos subagentes `maligno-*`: consulte-os em vez de supor. Não varra `Materias de aula/`.
- Código em Java 8, sem `var`, `record`, streams ou lambdas. Compile com `javac -encoding UTF-8 *.java`.
